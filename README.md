# NYC Taxi Trip Data Warehouse & BI System

A complete Data Warehousing and Business Intelligence solution developed using the NYC Taxi Trip dataset.

## Project Overview

This project demonstrates the implementation of a modern BI pipeline including:

* ETL development using SSIS
* Star schema data warehouse design
* Slowly Changing Dimensions (SCD)
* SSAS multidimensional cube creation
* OLAP analysis operations
* Power BI dashboard development
* DAX measures and reporting

---

## Technologies Used

* SQL Server
* SSIS
* SSAS
* Power BI
* DAX
* Excel PivotTables
* ETL
* OLAP

---

## Features

### Data Warehouse

* Star schema implementation
* Fact and dimension tables
* Slowly Changing Dimension handling
* Surrogate key implementation

### ETL Pipeline

* CSV data extraction
* Data transformation and cleansing
* Fact and dimension loading
* Accumulating fact table updates

### OLAP & Cube

* SSAS cube deployment
* Hierarchies and dimensions
* Roll-up and drill-down operations
* Slice and dice analysis

### Power BI Analytics

* Interactive dashboards
* Drill-through reports
* Cascading slicers
* KPI cards and visual analytics
